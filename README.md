# Image Processing with NumPy

In this project, we convert an image into a **NumPy array** and explore different ways of analyzing and transforming it.  
The implementations in this project include:

- 🖼️ **Slicing the image** to work with specific regions  
- 🎨 **Applying custom filters based on RGB values** of pixels to highlight or transform image properties  
- 🔍 **Extracting and analyzing pixel data** across rows and columns for deeper insights  

This repository demonstrates how raw images can be represented as arrays and manipulated at the pixel level using Python and NumPy, with clear visual outputs to illustrate each step.

## ⚙️ Requirements

- Python 3.14
- Jupyter(ipynb)
- NumPy
- Matplotlib
- Pillow (PIL)

## 🚀 How to Run

First, clone the repository:

```bash
git clone https://github.com/masihch/image-processing-numpy.git
cd image-processing-numpy

```
Then, run the main Python file directly from the root folder:
```bash
jupyter notebook Picture_Filter_Numpy.ipynb

```
